How these get built

The same four rules, every time.

  • It works offline. If an app needs a server to do its main job, it breaks in a parking garage. These don't.
  • No account. You shouldn't have to hand over an email address to print an envelope.
  • Your data stays yours. Nothing is uploaded to be read, scored, or trained on. There's no analytics SDK collecting what you type.
  • It says so when it can't. An app that silently fails is worse than one that admits it. These tell you.
